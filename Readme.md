# 📚 Book Recommendation System

A Streamlit-based book recommendation system using item-based collaborative filtering.

## 🔍 Features

- Personalized book suggestions
- Cosine similarity-based filtering
- Cover images via OpenLibrary
- Displays title, author, and average rating
- Elegant Streamlit UI with background image

## 🛠️ Tools Used

- Python
- Pandas
- Scikit-learn
- Streamlit
- OpenLibrary API
